# Thermal Conductivity Integrator (`integrate.py`)

This script integrates the scaled heat flux autocorrelation function (HFACF) to obtain the thermal conductivity. It also provides a convergence analysis by averaging over the final 10% of the integrated curve.

## Command-Line Arguments

**text**

```
python integrate.py <corrfile>
```

| Argument | Description                                                                                                        |
| -------- | ------------------------------------------------------------------------------------------------------------------ |
| corrfile | The input file containing the scaled HFACF. This is typically the `corr.txt` file generated by `calc_corr.py`. |

## Input File Format

The file must have at least two columns: time and the HFACF. The script expects that the first column is time and the subsequent columns are correlation functions from different trajectories (or components). The format is the same as the output of `calc_corr.py`:

time C1 C2 ... C20

## Calculation Steps

1. **Data Reading** : The function `read_data` reads the file, skipping lines starting with `#`. It separates the time column (column 0) and all correlation data columns (columns 1 to N).
2. **Numerical Integration** :

* For each correlation data column (i), it performs cumulative trapezoidal integration using `scipy.integrate.cumtrapz`: hcf_i(t) = ∫₀ᵗ C_J(t') dt'.
* The integration is performed with respect to the corresponding time array.

1. **Convergence Analysis** :

* The final 10% of the integrated data points (the "plateau") are extracted: `vals_final = vals_mean[int(0.9*N):]`.
* The average of this plateau region is reported as the thermal conductivity: κ = V / (3 k_B T²) × average of plateau.
* The standard error of the mean (SEM) over the plateau region is calculated to provide a statistical uncertainty.

1. **Output** :

* **Terminal Output** : Prints the average κ and its SEM in a formatted string: `<average_kappa> <std_error>`.
* **`hcf.txt`** : Writes the time and the cumulative integral (average over all trajectories) to a file.

## Important Notes

* The script assumes that the HFACF has decayed sufficiently by the end of the simulation, so that the integrated value has reached a plateau.
* The final output κ is in units of  **W/(m·K)** , as long as the input HFACF (`corr.txt`) has been properly scaled by `calc_corr.py`.
* The choice of the plateau region (90% onward) is a heuristic. For some systems, you may need to adjust this to ensure convergence.

## Usage Example

**text**

```
# Integrate the scaled HFACF
python integrate.py corr.txt > kappa.txt

# The terminal output is captured in kappa.txt
# The cumulative integral is saved in hcf.txt
```
